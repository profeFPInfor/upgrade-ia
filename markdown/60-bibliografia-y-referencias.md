## 60.6 Nota sobre la verificación

- Las URLs se comprobaron mediante peticiones HTTP en la fecha de redacción.
- Algunos sitios redirigen a una versión con idioma o a una ruta nueva; se conserva la URL canónica cuando se conoce.
- Las versiones de las herramientas cambian: consulta la documentación vigente antes de depender de una opción concreta.
- Las fuentes oficiales tienen prioridad sobre blogs y tutoriales de terceros.
- Las características marcadas como extensión o plataforma pueden cambiar sin que cambie la especificación CommonMark.
- Cuando una función no forma parte de Markdown estándar, se indica explícitamente en el texto.
