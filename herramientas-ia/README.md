# Herramientas de IA

Caja de herramientas transversal: cada herramienta se documenta **una sola vez** aquí, y las fases del [proceso](../proceso/) la enlazan cuando la usan.

| Herramienta | Estado | Para qué |
|-------------|--------|----------|
| [OpenCode](opencode/) | Elegida para el taller | Agente de programación en terminal, escritorio y web |

Otras herramientas del temario (IDEs, LLMs gratuitos, agentes, skills, plugins) se añadirán en su propia carpeta cuando haya material.

## Plantilla de una herramienta

1. Qué es y para qué sirve.
2. Instalación y primeros pasos.
3. Configuración.
4. En qué fases del proceso se usa y cómo.
5. Límites, costes y alternativas.
6. Fuentes oficiales.
